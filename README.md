# Flash-code - Renomeador de arquivos

Aqui guardei um pequeno notebook que usei para renomear arquivos de um repositório de imagens de placas.
Normalmente faço pequenos códigos em python que me permitem automatizar minhas tarefas.

## Funcionalidades
1. **Extração Automática:** Descompacta arquivos de um diretório `.zip` inicial para uma pasta temporária.
2. **Ordenação e Padronização:** Lista os arquivos em ordem alfabética e os renomeia seguindo um padrão sequencial numérico (`Placa_WEG1.jpg`, `Placa_WEG2.jpg`, etc.).
3. **Conversão de Estrutura:** Move os arquivos para uma nova estrutura de diretórios organizada (`placas/WEG/`).
4. **Limpeza e Compactação:** Remove os resquícios temporários para otimizar o espaço em disco e gera um novo arquivo `.zip` pronto para exportação.
5. **Download no Colab:** Executa o download automático do arquivo gerado diretamente para a máquina local.
